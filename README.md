# Рудновская Ольга Алексеевна — production site

Статический многостраничный сайт: HTML5 + CSS3 + Vanilla JavaScript. Сборщик и backend не требуются.

## Страницы
- `index.html` — Главная
- `services.html` — Услуги
- `about.html` — Обо мне
- `prices.html` — Цены
- `contacts.html` — Контакты

## Локальный запуск
Можно открыть `index.html` напрямую. Для удобной проверки всех страниц рекомендуется VS Code + Live Server.

## Материалы, которые ещё ожидаются от клиента
- оригинальный логотип/знак с вывески;
- портрет Ольги и фото во время работы;
- фото кабинета/входа;
- реальные фотографии работ с разрешением на публикацию;
- реальные отзывы;
- подтверждённые образование, обучение, стаж и сертификаты;
- точная инструкция прохода;
- финальное согласование формулировки блока о ДНКОМ;
- полный прайс, если он шире текущих подтверждённых позиций.

## Перед индексацией после получения production URL
1. В пяти HTML-файлах добавить `canonical` и `og:url` с финальным URL страницы.
2. В `sitemap.xml` заменить `https://DOMAIN_AFTER_DEPLOY` на финальный origin.
3. В `robots.txt` раскомментировать строку Sitemap и указать финальный абсолютный URL.
4. Повторно проверить все пять production URL.

## Netlify
Build command: не требуется. Publish directory: корень репозитория (`.`), если файлы лежат в корне.
